# What is LiteLLM?

LiteLLM is a Python library that provides a simple and consistent API for using Large Language Models (LLMs) from different providers. It allows you to use the same code to interact with various LLM providers, such as OpenAI, Anthropic, Google, and many others.

## Why use LiteLLM?

- **Simple API**: LiteLLM provides a simple and consistent API for using LLMs from different providers.
- **Easy to use**: LiteLLM is easy to use and can be integrated into your existing projects with minimal changes.
- **Wide range of providers**: LiteLLM supports a wide range of LLM providers, including OpenAI, Anthropic, Google, and many others.
- **Cost-effective**: LiteLLM is cost-effective and can help you save money on LLM usage.
- **Open-source**: LiteLLM is open-source and can be used for free.

## How to install LiteLLM?

Installing LiteLLM is very easy. You can install it using uv. Open terminal and run the following command:

```bash
uv tool install "litellm[proxy]"
```

To check if it is installed correctly, run the following command:

```bash
litellm --version
```
